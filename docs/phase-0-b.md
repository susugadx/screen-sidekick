# Phase 0-B

Phase 0-B adds the first browser-to-Rust vertical slice.

## In Scope

- Chrome/Edge side panel capture initiated by a user click.
- URL, title, selected text, visible buttons, visible inputs, and screenshot
  metadata capture.
- Loopback HTTP bridge on `127.0.0.1` with a per-run bearer token.
- Rust normalization from `raw_browser_context.v0.1` to `ScreenContext v0.1`.
- Safety review, sanitized ScreenContext JSON preview, and Codex prompt preview.
- Tauri/Leptos desktop shell that displays bridge status, URL, and token.

## Out of Scope

- Browser automation.
- MCP execution.
- Computer Use.
- Local repository editing.
- Automatic Codex submission.
- Raw DOM, cookies, localStorage, sessionStorage, hidden input values, password
  values, tokens, API keys, card numbers, or 2FA codes.

## Bridge Contract

- `POST /v0/capture`
- Bind address: `127.0.0.1` only.
- Auth: `Authorization: Bearer <token>`.
- Origin: `chrome-extension://...` only.
- Body: JSON with `schema_version = "raw_browser_context.v0.1"`.
- Response:
  - `screen_context_json`: pretty JSON generated from `SanitizedScreenContext`.
  - `prompt_text`: generated by `crates/prompt` from `SafetyReview`.
  - `safety`: danger/masking summary without raw page text or matched keywords.

## Running

Install extension dependencies:

```sh
npm --prefix apps/extension install
npm --prefix apps/extension run build
npm --prefix apps/extension test
node apps/extension/check-manifest.mjs
```

Load `apps/extension` as an unpacked extension after building.

Run the desktop app after installing Tauri v2 OS prerequisites, `cargo-tauri`,
`trunk`, and the wasm target:

```sh
rustup target add wasm32-unknown-unknown
cargo tauri dev --config apps/desktop/src-tauri/tauri.conf.json
```

If invoking from `apps/desktop/src-tauri`, use:

```sh
cargo tauri dev
```

Copy the bridge URL and token from the desktop window into the extension side
panel, then use Capture from the side panel.

## Checks

```sh
cargo fmt --all -- --check
cargo clippy --workspace --all-targets -- -D warnings
cargo test --workspace
npm --prefix apps/extension run typecheck
npm --prefix apps/extension run build
npm --prefix apps/extension test
node apps/extension/check-manifest.mjs
cargo test --manifest-path apps/desktop/src-tauri/Cargo.toml --no-default-features
cargo check --manifest-path apps/desktop/src-tauri/Cargo.toml
cargo check --manifest-path apps/desktop/ui/Cargo.toml --target wasm32-unknown-unknown
```

The default desktop check requires system webview dependencies. The UI check
requires the wasm target; Trunk is required for the full Leptos asset build.
